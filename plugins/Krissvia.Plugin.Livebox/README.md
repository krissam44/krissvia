# Krissvia.Plugin.Livebox

Présence des téléphones suivis et supervision de la connexion Internet, par l'API locale de la Livebox (lecture
seule). Voir `docs/PRESENCE.md`.

Lancé et réglé depuis la page Services du cœur : adresse de la box, mot de passe administrateur, appareils suivis
(adresse MAC + nom ; le journal du plugin liste les appareils que voit la box). Hors du cœur, les mêmes réglages
vont dans `appsettings.Local.json` (modèle : `appsettings.Local.example.json`, jamais versionné).
